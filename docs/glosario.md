# Glosario

- **Libro:** título del catálogo. Tiene una cantidad de ejemplares.
- **Ejemplar:** copia física de un libro.
- **Préstamo:** un alumno se lleva un ejemplar por un tiempo.
- **Préstamo activo:** todavía no fue devuelto.
- **Vencido:** préstamo activo cuya fecha de vencimiento ya pasó.
- **Renovación:** extender el préstamo 7 días más (una sola vez).
- **Reserva:** el alumno se anota para un libro que no tiene ejemplares libres.
- **Reserva en espera:** está en la fila, todavía no hay ejemplar.
- **Reserva lista:** hay un ejemplar guardado para ese alumno por 48 horas.
- **Sanción:** período en el que el alumno no puede pedir libros por devolver tarde.
- **Disponibles:** ejemplares totales − préstamos activos − reservas listas.
