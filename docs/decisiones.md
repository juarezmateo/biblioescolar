# Decisiones (pregunta → respuesta)

## Préstamos
- ¿Cuántos días dura un préstamo? → 7 días.
- ¿Cuántos libros a la vez? → 3 como máximo.
- ¿Puede llevarse dos veces el mismo libro a la vez? → No.
- ¿Qué pasa si tiene un libro vencido? → No puede retirar otros hasta devolverlo.

## Renovaciones
- ¿Cuántas veces se renueva? → Una sola, por 7 días más.
- ¿Cuándo no se puede renovar? → Si ya está vencido o si alguien reservó el libro.

## Reservas
- ¿Cuándo se puede reservar? → Solo si no hay ejemplares disponibles.
- ¿Cuántas reservas por alumno? → 2 como máximo.
- ¿Cuánto tiempo se guarda el libro al reservante? → 48 horas, después pasa al siguiente.
- ¿En qué orden? → Por orden de llegada.

## Sanciones
- ¿Cuánto es la sanción? → 2 días sin poder pedir por cada día de atraso.
- ¿Hay tope? → Sí, 30 días.
- ¿Se suman? → No, queda la sanción que termine más tarde.

## Permisos
- ¿Quién presta y recibe? → Solo el bibliotecario.
